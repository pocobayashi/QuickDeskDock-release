## 📖 О программе QuickDeskDock

**QuickDeskDock** — это мощный инструмент повышения продуктивности для Windows, оснащенный умными боковыми выдвижными панелями и стильным прозрачным виджетом часов.

Программа скрытно ожидает по краям экрана, не мешая работе, и мгновенно раскрывается при наведении мыши, открывая доступ к папкам, программам, заметкам, почте и счетчикам.

---

## ✨ Основные возможности

1. **📂 Двусторонние выдвижные панели (Dual Edge Dock)**: Закрепляются на левом и правом краях экрана, плавно выдвигаются и автоматически скрываются.
2. **📁 QuickFolder (Быстрый доступ к папкам)**: Цветовая маркировка папок, просмотр и запуск недавних файлов прямо из панели (сворачивание папок).
3. **🚀 QuickApps (Панель запуска приложений)**: Быстрый запуск часто используемых программ с индивидуальным распределением по сторонам.
4. **📝 QuickMemo (Встроенный блокнот)**: Быстрые заметки с автосохранением через 500 мс и шифрованием Windows DPAPI.
5. **📧 QuickOutlook (Интеграция с Outlook)**: Просмотр непрочитанных писем и создание шаблонов в один клик с автоматической подписью.
6. **🔢 QuickCounter (Мульти-счетчик)**: Удобный подсчет выполненных задач с надежным сохранением значений.
7. **🕒 Прозрачный виджет часов (Clock Widget)**: Цифровой и аналоговый режимы, полная прозрачность (от 0% до 100%), шрифты и тени.
8. **🎨 Продвинутая палитра цветов (Color Picker)**: Цветовой круг, ползунки RGB, яркость, HEX-код и готовые наборы цветов.
9. **🌐 Мультиязычный интерфейс**: Мгновенное переключение на все основные языки мира.
10. **⚡ Автообновление (Velopack Engine)**: Мгновенная загрузка обновлений и перезапуск в один клик.

## 🚀 Установка и обновление

### 📥 Первая установка
1. Скачайте установочный файл (`QuickDeskDock-Setup.exe`) со страницы [**Releases**](https://github.com/pocobayashi/QuickDeskDock-release/releases/latest).
2. Запустите exe-файл: права администратора не требуются, быстрая установка в каталог пользователя с созданием ярлыков.

### 🔄 Обновление
- Нажмите **`[ 🔄 Проверить обновления ]`** в настройках программы или в меню трея для автоматического обновления в один клик.
