## 📖 关于 QuickDeskDock

**QuickDeskDock** 是一款高效的 Windows 桌面增强工具，配备屏幕左右双侧滑出式抽屉和可高度自定义的透明时钟小部件。

平时静止隐藏在屏幕边缘不干扰任何工作区，只需鼠标轻触或点击，即可瞬间唤出文件夹、常用软件、便签、邮件和计数器。

---

## ✨ 核心功能

1. **📂 双侧滑出抽屉 (Dual Edge Dock)**: 停靠于屏幕左右两侧边缘，鼠标悬停或点击即可平滑滑出，离开后自动收起。
2. **📁 QuickFolder (高速文件夹管理)**: 注册常用工作目录，以彩色标签分类，直接在抽屉内查看与打开最近文件（支持折叠）。
3. **🚀 QuickApps (应用快捷启动器)**: 为常用软件创建启动图标与符号，支持独立分配至左侧、右侧或双侧菜单。
4. **📝 QuickMemo (常驻快速便签)**: 随时记下灵感与待办事项，输入后 0.5 秒自动保存，采用 Windows DPAPI 强加密。
5. **📧 QuickOutlook (邮件联动与起票)**: 与电脑中的 Outlook 本地联动，支持快速查看未读邮件、一键新建草稿与自动签名应用。
6. **🔢 QuickCounter (多项目计数器)**: 自由添加计数项目、增减操作与自动持久化保存。
7. **🕒 透明时钟小部件 (Clock Widget)**: 数字/模拟时钟切换，支持 0%~100% 完全透明背景、精选字体与轮廓阴影修饰。
8. **🎨 专业调色盘 (Color Picker)**: 色相环、RGB 滑块、明度滑块、十六进制颜色代码与预设色板。
9. **🌐 全球多语言支持**: 瞬时切换多国语言界面。
10. **⚡ 自动差分更新 (Velopack Engine)**: 在设置管理窗口中一键检查并下载更新包，自动重启更新。

## 🚀 安装与更新

### 📥 首次安装
1. 从 [**Releases 发布页**](https://github.com/pocobayashi/QuickDeskDock-release/releases/latest) 下载最新安装程序 (`QuickDeskDock-Setup.exe`)。
2. 运行下载的 exe 文件，无需管理员权限，秒级安装到用户目录并自动创建桌面与开始菜单快捷方式。

### 🔄 软件更新
- 在设置管理界面右上角点击 **`[ 🔄 检查最新版本 ]`** 或在任务栏托盘图标右键菜单中选择更新即可一键完成。
