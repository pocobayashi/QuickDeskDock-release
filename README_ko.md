## 📖 QuickDeskDock 소개

**QuickDeskDock**은 화면 좌우 가장자리에 깔끔하게 숨겨지는 슬라이드 방식의 드로어와 투명 시계 가젯을 결합한 **고성능 데스크톱 생산성 도구**입니다.

작업 공간을 방해하지 않고 화면 끝에 대기하다가, 마우스 호버 또는 클릭 한 번으로 폴더, 앱 런처, 메모, 이메일, 카운터에 즉시 접근할 수 있습니다.

---

## ✨ 주요 기능

1. **📂 듀얼 사이드 슬라이드 드로어 (Dual Edge Dock)**: 화면 좌우 가장자리에 상주하며 탭 클릭 또는 마우스 호버로 매끄럽게 슬라이드 전개 후 자동 수납.
2. **📁 QuickFolder (고속 폴더 감시 및 파일 접근)**: 색상 라벨로 폴더를 등록하고, 드로어 안에서 최근 파일을 바로 열람 및 실행 (폴더별 접기 지원).
3. **🚀 QuickApps (앱 런처)**: 자주 쓰는 프로그램을 아이콘/기호와 함께 등록. 좌측 전용, 우측 전용, 양쪽 공통 배치 지원.
4. **📝 QuickMemo (상주 퀵 메모)**: 화면 끝에서 바로 적는 내장 메모장. 입력 후 0.5초 만에 Windows DPAPI 암호화 자동 저장.
5. **📧 QuickOutlook (메일 연동 및 빠른 작성)**: PC의 Outlook과 연동하여 읽지 않은 메일 확인 및 기본 서명이 적용된 템플릿 메일 원클릭 작성.
6. **🔢 QuickCounter (멀티 카운터)**: 업무량이나 작업 횟수를 기록할 수 있는 다중 카운터 기능 (항목 자유 추가/자동 저장).
7. **🕒 투명 시계 위젯 (Clock Widget)**: 디지털/아날로그 전환, 0%~100% 완전 투명 배경, 폰트 및 외곽선/그림자 효과 커스터마이징.
8. **🎨 고기능 컬러 팔레트 (Color Picker)**: 색상 휠, RGB 슬라이더, 명도 바, HEX 코드 입력 지원.
9. **🌐 글로벌 다국어 지원**: 클릭 한 번으로 전 세계 주요 언어로 즉시 인터페이스 전환.
10. **⚡ 원클릭 자동 업데이트 (Velopack Engine)**: 설정 화면이나 트레이 메뉴에서 클릭 한 번으로 최신 패치를 다운로드하고 자동 재시작.

## 🚀 설치 및 업데이트

### 📥 처음 설치하시는 분
1. [**Releases 페이지**](https://github.com/pocobayashi/QuickDeskDock-release/releases/latest)에서 최신 인스톨러(`QuickDeskDock-Setup.exe`)를 다운로드합니다.
2. 관리자 권한 없이 즉시 설치되며 바탕화면 및 시작 메뉴에 바로가기가 생성됩니다.

### 🔄 업데이트 방법
- 설정 화면의 **`[ 🔄 최신 버전 확인 ]`** 또는 작업 표시줄 트레이 메뉴를 통해 자동 업데이트를 실행할 수 있습니다.
