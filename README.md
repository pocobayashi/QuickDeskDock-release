## 📖 QuickDeskDock とは？

**QuickDeskDock** は、Windows デスクトップの左右両端にスマートに格納される「せり出し式ドロワー」と、美しくカスタマイズ可能な「透過時計ガジェット」を中心とした**多機能デスクトップ拡張ツール**です。

作業スペースを邪魔することなく画面端に待機し、マウスを近づけるだけで必要なフォルダ、アプリ、メモ、メール、カウンターへ瞬時にアクセスできます。

---

## ✨ 主な機能

1. **📂 左右両サイドのせり出しドロワー (Dual Edge Dock)**: 画面の左右両端に常駐し、タブクリックまたはマウスホバーでスムーズにスライド展開。作業を終えると自動格納。
2. **📁 QuickFolder (高速フォルダ監視・ファイルアクセス)**: よく使うフォルダを色分けラベル付きで登録。ドロワー内から直接ファイル一覧を展開・起動（折りたたみ対応）。
3. **🚀 QuickApps (アプリランチャー)**: 頻繁に使うツールをアイコン・記号付きでクイック登録。左右個別または両メニュー共通の配置が可能。
4. **📝 QuickMemo (常駐クイックメモ)**: サッと書ける内蔵メモ帳。入力後 0.5 秒で自動保存（Windows DPAPI による暗号化保護）。
5. **📧 QuickOutlook (メール連携・自動起票)**: Outlook と連携し、未読メールの確認やワンクリック起票（既定署名の自動適用対応）。
6. **🔢 QuickCounter (マルチカウンター)**: タスク消化数やカウント項目を自由に増やして管理できるカウンター機能。
7. **🕒 透過時計ガジェット (Clock Widget)**: アナログ／デジタルの切替、厳選フォント、文字色、完全透過対応（0〜100%）、ドロップシャドウや縁取り装飾。
8. **🎨 本格派カラーパレット (Color Picker)**: 色相・彩度ホイール、RGB スライダー、明度スライダー、HEX 入力対応。
9. **🌐 グローバル多言語対応**: 世界各国の主要言語に即時切り替え可能。
10. **⚡ 自動アップデート (Velopack Engine)**: 管理画面またはトレイから「最新版を確認」を押すだけで差分高速アップデート。

## 🚀 インストール / アップデート

### 📥 初めてお使いの方
1. [**Releases ページ**](https://github.com/pocobayashi/QuickDeskDock-release/releases/latest) から最新のインストーラー（`QuickDeskDock-Setup.exe`）をダウンロードします。
2. ダウンロードした exe を実行すると、管理者権限不要でユーザー領域に自動インストールされ、即座に起動します。

### 🔄 アップデート方法
- 設定画面（右上または「常駐・追加削除管理」タブ）の **`[ 🔄 最新版を確認 ]`** ボタン、またはタスクトレイのメニューからワンクリックでアップデート可能です。
